# Cerebrum 心境适配

筷子窄适配 Cerebrum 0.1.7 的情绪评价与衰减算法，固定上游提交 `b8fbe018f0d3d29ad92a97180c0f7387d8d524c6`。上游为 MIT，许可见 `notices/cerebrum-MIT-LICENSE`。不加载上游完整插件、人格系统、发送器或管理服务。

配置 `cerebrum.enabled: true` 后，现有 Router 的事件判断会同时取得公开实际经历的证据，模型通过同一个 `chopsticks_decide` 提交原有行动和可选 `moodUpdatesJson`。没有独立心境 Worker，也没有心境专用模型调用。心境与行动决定在同一个 SQLite 事务内保存。

首期心境只为公开对话的表达提供固定情绪标签和强度，不进入 Router 的行动选择，不授予发送或其他权限。原有人设、记忆、事实与平台确认回执继续有效。模拟状态和真实经历分别存储，评价必须引用该轮提供的精确事件 ID。

公开来源限 QQ 群与 B 站公开实际经历；私聊、管理员对话、内部事件、导入历史、合成事件和定时器本身均不作心境证据。新启用时从事件日志当前水位开始，不重评旧历史。实际收到的消息、具有平台消息编号的已发送回执以及已标记实际经历的任务结果可入选。公开定时机会可携带尚未处理的真实经历。

每轮按持久化游标向前读取最多 128 行，证据最多 8 项、4,000 字符；文本和元数据在数据库取出前设长度上限。成功判断会在同一事务确认已扫描区间，即使模型没有评价也会继续前进。失败回滚后可再次提供。持久化游标阻止旧事件重复影响心境，短期去重项随事务清理。

同一个事件数据库新增 `cerebrum_state`、`cerebrum_cursor`、`cerebrum_applied`、`cerebrum_history`。状态与游标各一行，历史最多 30 项，常规事务内短期去重不超过 8 项，事务结束后清理。读取时按本地时间计算衰减，不启动后台循环。未有有效评价时界面显示尚无情绪记录。

现有管理后台导航增加“心境”，页面为 `/api/chopsticks/mood`，复用 DSH 登录和 `chopsticks-console` RPC。它展示模拟状态、公开来源编号和最近变化，并支持：

- 暂停：不更新，不参与表达。
- 观察：更新状态，不参与表达。
- 表达：更新状态，参与表达。

切换以服务器确认结果为准。管理页只使用本地静态资源，不引入新端口、数据库中间件、GPU 或第三方数据服务。

回滚可关闭配置或恢复先前代码与配置；保留事件、平台回执、原有历史和心境表，避免回滚导致事实倒退或重复发送。重新启用会沿用持久化游标和模式。


部署时须考虑现有的 socket 激活入口：记录原状态，临时停止 LAN socket 和转发服务，再停止 DSH；确认全部停止后替换代码与配置，恢复后端和原有入口状态。只停止 DSH 可能被入口的新连接重新拉起。不要永久关闭或修改入口，也不要回滚经历数据库。
