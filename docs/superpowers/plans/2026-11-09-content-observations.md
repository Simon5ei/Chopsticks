# 四平台观看证据与私有回顾

**目标** 让四个平台继续使用现有浏览轮，记录鱼实际读取的材料、缺失项和主观感想，并按范围生成私有日终回顾。

**约束** 使用现有 Router、平台会话、owner 与回执。平台分别启用，浏览轮只读，公开与好友范围分开。先用隔离 DSH 和合成素材验证。部署属于后续阶段。

1. 写 B 站回归测试。标题、空字幕和封面不得成为视频正文证据。有效字幕与关键帧可以在同一浏览轮留证，收尾写私有感想。重启后保持记录，日报只按日期与范围有界读取。
2. 在 B 站工具服务产生结构化字幕和帧证据，沿浏览轮绑定采集。接入现有事件与回执路径，给自动浏览轮添加只读约束。运行 B 站隔离回归。
3. 将小黑盒正文/少量回帖、QQ 空间好友正文、抖音描述/图文/可取证据接入同一记录，保持内容能力分级与范围。运行平台适配器及隔离 Router/原生工具回归。
4. 私有回顾提供简版、详细、关闭三档，闭合浏览轮数据按北京时间归档。做类型检查、全套回归、源码复核和隔离运行，汇报实测范围。
