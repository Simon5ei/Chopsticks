# 筷子运行控制台与追踪

Spec: 用户要求整理控制台、打印日志、直观追踪模型已经输出的思考内容和工具调用。保持独立，不接入 SessionCross。每日插件调研已创建，安装另待用户审批。

## Design
- 在 DSH 原生 authenticated settings.section 中提供“筷子”入口，四页：运行概览、事件链路、思考与工具、日志。无需新服务端口。
- Read-only RPC method chopsticks-console at /api/chopsticks-console. Endpoints overview, events, traces, logs. Envelope follows native connection.rpc.call('/api','chopsticks-console',{endpoint,payload}). Errors {ok:false,error:{message}}, success {ok:true,value}.
- overview => {health,model,counts,sessions:[{sessionId,channel,role}],tasks:[]}; events => {items:[{id,seq,kind,channel,text,at,routeState,sessionId}],nextBeforeSeq}; traces/logs => {items:[{seq,at,kind,level,sessionId,channel,eventId,callId,name,text,data}],nextBeforeSeq}. Payload bounded limit (default 50 max 100), beforeSeq, sessionId, eventId, channel, query.
- Persist normalized native assistant reasoning/text, tool call/result, turn lifecycle and retries in bounded SQLite trace table. Only actual emitted reasoning; no fabricated/internal hidden traces. Mask credentials/signatures/base64, bound payload sizes and retention. Server logger prints metadata only, console detail is private owner-visible. Do not put raw prompts/role/credentials in logs.
- Record evaluation sessions and source IDs; correlate source event -> Router decision -> execution session -> tool -> confirmed output. Do not duplicate canonical events or alter delivery semantics. Failure of optional telemetry must not stop fish runtime.

## Tasks
1. Backend: trace store, native event normalization, redaction, RPC queries and authenticated registration; runtime hooks and tests before implementation. Own host/observability.mjs, host/console.mjs, tests/console.test.mjs, host/index.mjs, host/runtime.mjs.
2. Frontend: independent new console/client.js, native client package registration and tests. Chinese labels, coherent visual hierarchy, status cards, searchable timeline, source/session filters, expandable reasoning/tool payloads, auto-refresh/pause/error states and redacted JSONL export. Avoid unsafe HTML. Own console/, package.json, package-lock.json, tests/console-client.test.mjs. Use API above. No SurfCore/SessionCross dependency.
3. Root integration: verify auth with native DSH, isolated model traces, full tests, visual QA, review; back up and deploy when fish idle; push authorized repository; document access/limits/rollback. No synthetic public messages, no history rewrites, no plugin installations.

## Acceptance
Test redaction, bounded queries/retention, malformed events, tool result actual shapes, source correlation, unknown endpoints, read-only auth and UI pagination. Native isolated DeepSeek run emits reasoning/tool records visible in console; unauthenticated request rejected. Production remains DeepSeek and QQ healthy after deployment. Data stays outside Git.
