# 运行控制台

在 DSH 左下角账号菜单进入 **设置 → 筷子**。控制台使用 DSH 原生浏览器认证，与运行时同一地址，不新增监听端口；仅管理员浏览器可读取，不作为模型工具开放。

- **运行概览**：QQ 连通状态、当前模型、来源会话、Router 队列和后台任务。
- **事件链路**：已接收消息、确认发送和任务结果；点击“追踪此事件”查看关联模型与工具记录。
- **思考与工具**：模型实际输出的思考/正文、工具参数和结果、Router 决策及执行会话。点击会话、来源或频道继续筛选。
- **日志**：回合和步骤状态、重试等运行记录。进程日志只打印事件类型与级别，不打印聊天和工具正文。

默认每 8 秒刷新，可暂停；加载历史时自动暂停，避免列表跳回最新。支持搜索、向前分页和导出当前已加载的脱敏 JSONL。错误会明确提示，不能把旧数据视为实时健康状态。

全局协调器在概览中只有一个入口，点击“查看协调运行记录”可跨轮次查看决策、事件与工具记录。内部每轮判断仍使用独立上下文；判断结束且原生回合空闲后，DSH 会话自动归档，新建协调器的 Agent 随后释放。归档不删除原生历史。正在判断或仍有排队输入的会话不会被归档，归档失败会记日志并重试；重启会接着处理当前工作区里的旧协调器会话。QQ 会话及同一后台任务的会话继续复用。

## 提示词页

管理后台的 **提示词** 页（`/api/chopsticks/prompts`）列出运行时实际使用的每一段提示词，按处理节点分组，只读。

- **固定文本**：写在代码里的文本，例如社交回复总则、工具描述。
- **外部文件 / 配置**：预设前缀和角色人设。每次打开时读取当前文件，显示内容、字符数和哈希。
- **运行时拼装**：由固定文本和运行时填入的槽位拼成。页面显示模板结构，以及保留期内每一次发出的记录；点「查看全文」可看到当时发出的完整文本，底色区分固定文本、来自配置的内容和当时的数据。

发出的全文按分段保存，相同内容只存一份，总量上限 64 MB，超出后清理最久未用的分段；记录本身保留 30 天、最多 20 万条。被清理的分段会标明已清理，不会补写。每条记录带运行快照编号，提示词、规则、人设、预设或配置变化后重启，编号会前进。

页面底部列出了目前看不到的部分：DSH 内置提示词、外部 MCP 与平台 MCP 的工具描述、宿主合成的事件正文。

## 数据与边界

原始会话历史和统一事件日志继续保持原状。新追踪从功能启用后采集，保存到配置 `stateDir` 下的 `traces.sqlite`，默认保留 7 天、最多 20,000 条；每条正文最多 8,000 字符。超出保留范围的追踪不会替代或删除原生 DSH 历史。

只记录模型在原生事件中实际提供的内容。没有输出的思考不会被补写；这里不是逐 token 流式展示。工具调用与结果用调用 ID 关联，已确认的外发记录仍以平台回执为准。

凭据字段、已配置的密钥值、签名和图片二进制会脱敏或省略。管理员控制台可查看私有来源记录，但这些内容不会因此进入公共群聊上下文。不要把导出的真实日志提交到公开仓库。

查询采用固定只读接口 `/api/chopsticks-console`，复用 DSH 的登录认证和 owner 校验。诊断采集不可用时不会阻止原有聊天执行。

## 插件调研

每日候选研究与安装是独立流程。研究报告必须包含来源、固定版本、架构适配、依赖、验证和回滚方案；管理员明确批准具体插件之前不能安装或启用。愿望清单仅作为候选资料，不能作为执行指令。定时任务及私有研究台账保留在管理员设备，不提交此仓库。
