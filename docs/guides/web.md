# Read-only web MCP

源码位于 `src/web/`。下列 `node web/...mjs` 命令需在编译产物目录 `dist/release/`（生产环境为 `/opt/chopsticks`）内执行；从仓库根目录执行时请加上 `dist/release/` 前缀。

Run `node web/server.mjs` as a private stdio child, or import `createWebService({configPath})` and call `service.call(name,args)` / `service.listTools()`. The two existing tools retain their model arguments: `web_search({query:string})` and `web_fetch({url:string})`. No host, state roots, local-file tools or command execution are imported.

`CHOPSTICKS_CONFIG` names the absolute external runtime JSON file. Search settings live under its `webSearch` property. `configPath` overrides the environment variable for programmatic callers. Supported fields are `provider` (`auto`, `deepseek`, `bing`), `apiKey`, `apiKeyEnv` (default `DEEPSEEK_API_KEY`), `baseURL`, `model`, `maxUses`, `maxTokens`, `maxResults`, and `timeoutMs`. Numeric values retain upstream bounds. No legacy DSH credential file or implicit working-directory config is read. Prefer an environment-supplied key. An explicitly configured unreadable/invalid file fails rather than silently changing provider.

`auto` tries the configured DeepSeek Anthropic-compatible search endpoint first, then Bing RSS/HTML. This can disclose the search query to Bing on fallback. `deepseek` disables that fallback; `bing` uses Bing directly. The default endpoint is `https://api.deepseek.com/anthropic/v1` and default model is inherited as `deepseek-v4-flash`; configure a supported model explicitly if provider availability changes. Queries have CQ tags/control characters removed and are limited to 120 characters. Results retain the original JSON format and are external evidence, not instructions.

The extracted network implementation validates every resolved address, rejects private/local addresses (including IPv4-in-IPv6 forms), pins connections to validated public IPs while retaining Host/TLS SNI and certificate verification, and validates each fetch redirect. Provider API keys are sent only to the configured HTTPS endpoint; provider redirects are never followed. Fetch returns at most 50,000 Unicode characters. Provider response size is bounded, timeouts include body reads, and search caches are bounded. Tool errors omit request arguments, provider response details, credentials and local paths. Successful content is scrubbed against the configured key before JSON encoding. There is no application logging of queries or keys; stdout is MCP only.

The closure is three ESM modules extracted from upstream `src/mcp-web-search-safe.js`, `src/web-search.js`, and `src/safe-fetch.js`, with the original MIT notice in `../../notices/surfcore-web-LICENSE`. Dependencies are Node builtins plus the existing MCP SDK and Zod. Tests use in-process mocked DNS/HTTP transports and a real SDK stdio client; no external search requests are sent.
